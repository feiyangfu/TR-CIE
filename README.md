# [ICML'26] A Time-Reparameterized Cumulative Intensity Extrapolation Sampler for Discrete Flow Matching
This repository officially houses the PyTorch implementation of the paper titled "A Time-Reparameterized Cumulative Intensity Extrapolation Sampler for Discrete Flow Matching
", which is accepted to ICML 2026.
# Sampling
Use ```discrete_solver.py``` to replace the sampling implementation in [DFM](https://github.com/facebookresearch/flow_matching/tree/main/flow_matching/solver).
